# PostgreSQL Production DBA Lab

A production-like PostgreSQL database administration environment
built to demonstrate practical PostgreSQL DBA skills.

## Project Objectives

This project demonstrates:

- PostgreSQL installation and configuration
- Database design and administration
- Role-based access control
- Streaming replication
- Backup and recovery with pgBackRest
- WAL archiving
- Point-in-Time Recovery
- PostgreSQL monitoring
- Performance troubleshooting
- Query optimization
- Incident simulation and recovery
- Linux and Bash automation

## Architecture

| Server | Role |
|---|---|
| pg-primary | PostgreSQL Primary |
| pg-standby | PostgreSQL Standby |
| pg-monitor-bkp | Backup and Monitoring |

## Technology Stack

- PostgreSQL 18
- Oracle Linux 8
- pgBackRest
- Bash
- SQL
- Prometheus
- Grafana
- Git
- GitHub
